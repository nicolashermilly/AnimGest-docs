01 Ce que permet le connecteur

Eliot est l'assistant IA intégré d'Anim'Gest : un widget de discussion qui répond à vos questions et vous aide au quotidien.

  • Assistant conversationnel dans l'application (widget Eliot).
  • Propulsé par l'API Anthropic (Claude) : vous fournissez votre propre clé.
  • Une clé par établissement : isolation et maîtrise de votre consommation.
  • Modèle configurable (Sonnet, Opus, Haiku) selon vos besoins et votre budget.
  • Clé chiffrée (AES-256), jamais affichée en clair.
02 Prérequis
Compte AnthropicUn compte sur console.anthropic.com avec un crédit (billing) actif.
Clé APIUne clé au format sk-ant-api03-…, à renseigner dans Paramètres › API › Eliot. Stockée chiffrée.
ModèleChoix du modèle Claude (Sonnet par défaut). Opus = plus puissant, Haiku = plus économique.
DroitsAccès administrateur à Anim'Gest pour saisir la clé.
03 Configurer le connecteur

  1. Créer une clé API

    Sur console.anthropic.com, ouvrez API keys et créez une nouvelle clé.

  2. Copier la clé

    Copiez la clé affichée (format sk-ant-api03-…) : elle n'est montrée qu'une fois côté Anthropic.

  3. Coller dans Anim'Gest

    Dans Paramètres › API › Eliot, collez la clé, puis Enregistrez.

  4. Choisir le modèle

    Sélectionnez le modèle (Sonnet par défaut). Au besoin, ajustez la créativité et la longueur des réponses.

  5. Tester

    Cliquez sur Tester la connexion : si la clé est valide, Eliot répond et l'assistant est prêt.
Crédit. La consommation est facturée par Anthropic sur votre compte. Surveillez votre solde via le lien Billing de la console.
04 Suivi & dépannage
CasSignification & action
Test 200Clé valide, Eliot est opérationnel.
Test 401Clé invalide. Vérifiez le format sk-ant-api03-… et recopiez la bonne clé.
Crédit épuiséEliot ne répond plus : rechargez votre compte Anthropic (lien Billing).
Réponses lentes / coûteusesChoisissez un modèle plus léger (Haiku) ou réduisez la longueur des réponses.
05 Bonnes pratiques
  • Une clé par établissement : ne partagez pas une clé entre plusieurs comptes.
  • Surveillez votre crédit Anthropic régulièrement.
  • Choisissez le modèle selon l'usage : Sonnet pour l'équilibre, Opus pour la finesse, Haiku pour l'économie.
  • En cas de doute sur une clé, révoquez-la dans la console et générez-en une nouvelle.
Confidentialité. Votre clé Anthropic ne doit jamais être partagée. Stockée chiffrée, non réaffichée après enregistrement.
