Taux de TVA

Le référentiel de vos taux de TVA : taux, libellé, code, et l'état actif ou inactif. Vérifié Août 2026

L'écran Taux de TVA porte la liste des taux que vous utilisez sur vos devis et vos factures. Chaque taux a quatre informations : le taux en pourcentage, un libellé lisible, un code et un état actif ou inactif. Vous ajoutez un taux avec le bouton Nouveau taux de TVA, vous en modifiez un avec Modifier, et vous basculez son état en cliquant sur la pastille Actif / Inactif.

Les quatre champs

Taux (%) : la valeur numérique, par exemple 20. C'est le seul champ obligatoire à la création.

Libellé : le texte que vous lisez dans les listes, par exemple TVA 20%.

Code : l'identifiant du taux, par exemple FR_20. C'est lui qui rattache le taux à vos documents. Deux codes différents désignent deux taux différents, même s'ils portent le même pourcentage.

Actif / Inactif : la pastille en fin de ligne. Un clic bascule l'état.

Procédure : ajouter un taux

  1. Cliquez sur Nouveau taux de TVA.
  2. Renseignez le taux, le libellé et le code.
  3. Cliquez sur Ajouter. Le taux apparaît dans la liste, triée par valeur croissante.

Bon à savoir

La liste est triée par taux croissant, pas par ordre de création.

Le bouton Supprimer retire définitivement un taux du référentiel. Si un taux ne doit plus être proposé mais que vous voulez en garder la trace, préférez le passer en Inactif plutôt que le supprimer.

Renseignez le code dès la création. Un taux sans code reste identifiable par son libellé sur cet écran, mais le code est ce qui le désigne de façon stable ailleurs dans le logiciel.

Et ensuite

Créer une nouvelle facture Émettre une facture directe : client, date et lignes. Une facture émise entre au FEC et devient définitive.
