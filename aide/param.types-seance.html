Types de séance

Vos types de séance : code, libellé, catégorie libre, métier de rattachement, durée par défaut, facturation et couleur d'agenda, avec un filtre par métier. En cours de mise à jour

L'écran Types de séance porte le catalogue de vos séances : ce que vous proposez, à quel métier cela se rattache, combien de temps cela dure par défaut, si c'est facturable, et de quelle couleur cela apparaît dans l'agenda. Créez-en un avec Nouveau type de séance, ajustez-le avec Modifier.

Les champs

Code : l'identifiant court du type, par exemple CONSULT.

Libellé : le nom lisible, par exemple Consultation.

Catégorie : un champ libre et optionnel. Vous écrivez le mot qui vous convient ; si vous le laissez vide, le type n'a simplement pas de catégorie. Ce n'est pas une liste fermée.

Métier : le métier auquel le type se rattache. Un type sans métier est marqué Non rattaché.

Durée par défaut (min) : la durée proposée quand vous planifiez ce type de séance. Elle est de 60 minutes tant que vous ne la changez pas, et reste modifiable séance par séance.

Facturable par défaut : indique si ce type est facturable sans que vous ayez à le préciser à chaque fois.

Couleur dans l'agenda : la couleur de ce type dans votre planning. Une couleur personnalisée est possible.

Le rattachement au métier

Des onglets Filtrer par métier en tête d'écran, avec un compteur par métier, permettent de ne voir que les types d'une activité. Tous les métiers rétablit la liste complète.

Un type marqué Non rattaché n'est pas en faute : c'est le bon réglage pour une séance que vous proposez quel que soit le métier exercé. Mais si vous exercez plusieurs activités et que votre liste de types devient longue, rattacher chaque type à son métier est ce qui rend l'écran de planification lisible.

Les couleurs prennent effet tout de suite

L'écran l'annonce lui-même : les couleurs sont appliquées immédiatement dans l'agenda après modification. Il n'y a rien à recharger ni à revalider. C'est agréable, et cela veut aussi dire qu'un essai de couleur est visible par toute votre équipe dans la seconde.

Bon à savoir

Un type que vous n'utilisez plus peut être passé Inactif plutôt que d'être retiré : vos séances passées gardent ainsi leur type.

La durée par défaut est une proposition, pas une contrainte : une séance plus longue que prévu se saisit normalement.

Sujets voisins

Paramètres Le point d'entrée de la configuration de votre espace, en cinq familles : identité et présentation, métier et activité, comptabilité et paiements, interfaces et communications, administration. Sélection Métier(s) Activer les modules correspondant à votre activité, et enregistrer vos deux attestations : ACACED et RC Pro, avec leur date d'expiration calculée et une alerte par email avant échéance. Agenda Vos séances vues dans le temps, par semaine, par mois ou en liste. L'agenda complète la liste des séances en montrant votre planning d'un coup d'oeil, et permet de déplacer un rendez-vous en le faisant glisser.
