01 Ce que permet le connecteur

SMTP permet d'envoyer vos e-mails (devis, factures, relances) depuis votre propre adresse professionnelle.

  • Envoi des documents directement aux clients.
  • Expéditeur à votre nom de domaine (meilleure délivrabilité).
  • Identifiants stockés chiffrés (AES-256).
  • Compatible avec la plupart des fournisseurs (OVH, Gmail, Microsoft 365…).
02 Prérequis
Serveur SMTPHôte et port fournis par votre fournisseur d'e-mail (ex. smtp.exemple.fr, port 587).
IdentifiantsNom d'utilisateur et mot de passe (idéalement un mot de passe d'application).
ExpéditeurAdresse d'envoi (à votre domaine), à saisir dans Paramètres › API › SMTP.
ChiffrementTLS (port 587) ou SSL (port 465) selon le fournisseur.
03 Configurer le connecteur

  1. Récupérer les paramètres SMTP

    Relevez l'hôte, le port et vos identifiants chez votre fournisseur d'e-mail.

  2. Saisir dans Anim'Gest

    Dans Paramètres › API › SMTP, renseignez hôte, port, utilisateur et mot de passe.

  3. Expéditeur & chiffrement

    Indiquez l'adresse d'expédition et le mode de chiffrement (TLS/SSL), puis Enregistrez.

  4. Tester l'envoi

    Cliquez sur Envoyer un e-mail de test : s'il arrive, le connecteur est opérationnel.
Délivrabilité. Configurez SPF et DKIM sur votre domaine pour éviter le classement en spam.
04 Suivi & dépannage
CasSignification & action
Test OKL'e-mail est parti : connecteur opérationnel.
Authentication failedIdentifiants incorrects : vérifiez utilisateur/mot de passe (mot de passe d'application si MFA).
Connection refused / timeoutHôte ou port incorrect, ou chiffrement inadapté (TLS vs SSL).
E-mail en spamConfigurez SPF/DKIM ; utilisez un expéditeur à votre domaine.
05 Bonnes pratiques
  • Préférez un mot de passe d'application dédié.
  • Expéditeur à votre nom de domaine, pas une adresse gratuite générique.
  • Activez SPF et DKIM pour la délivrabilité.
  • Testez après chaque changement de mot de passe.
Sécurité. Le mot de passe SMTP est stocké chiffré, jamais réaffiché après enregistrement.
