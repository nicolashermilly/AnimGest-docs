Calendly - Prise de rendez-vous

Synchronisez les rendez-vous pris en ligne via Calendly dans votre agenda. Connexion par Personal Access Token, webhooks signés, secrets chiffrés.

01 Ce que permet le connecteur

Calendly synchronise les rendez-vous pris en ligne par vos clients directement dans votre agenda Anim'Gest.

  • Les réservations Calendly remontent dans l'agenda (moins de double saisie).
  • Connexion par Personal Access Token (jeton personnel Calendly).
  • Webhooks signés (HMAC) vérifiés grâce à votre clé de signature.
  • Secrets stockés chiffrés (AES-256), jamais affichés en clair.
02 Prérequis
Compte CalendlyUn compte Calendly avec vos types d'événements configurés.
Personal Access TokenUn jeton généré depuis les paramètres développeur de Calendly, à coller dans Paramètres › Calendly.
Clé de signatureLa signing key du webhook Calendly, pour vérifier l'authenticité des notifications.
03 Configurer le connecteur

  1. Générer un Personal Access Token

    Dans Calendly (paramètres développeur), créez un jeton d'accès personnel.

  2. Coller dans Anim'Gest

    Dans Paramètres › Calendly, collez le token et la clé de signature, puis Enregistrez.

  3. Déclarer le webhook

    Dans Calendly, ajoutez l'URL de webhook fournie ; les nouvelles réservations seront notifiées à Anim'Gest.

  4. Tester

    Cliquez sur Tester la connexion : si le token est valide, vos types d'événements sont récupérés.
Limitation multi-établissements (en cours de résolution). Les webhooks Calendly ne transmettent pas l'identifiant d'établissement. La synchronisation automatique par webhook n'est donc pas encore disponible pour les comptes multi-établissements ; la connexion (token, récupération des événements) fonctionne normalement.

05 Bonnes pratiques
  • Conservez le Personal Access Token confidentiel ; régénérez-le en cas de doute.
  • Renseignez toujours la clé de signature pour sécuriser les webhooks.
  • Vérifiez que vos types d'événements Calendly correspondent à vos prestations.
Sécurité. Token et clé de signature sont stockés chiffrés, jamais réaffichés après enregistrement.
